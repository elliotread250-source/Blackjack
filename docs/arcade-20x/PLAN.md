## Motion system
- `js/motion/engine.js`: one `requestAnimationFrame` scheduler (`addTask(fn, {owner})`, tasks receive `dt`,
  `t`); visibility pausing; quality governor (samples frame times for 3 s, then continuously; steps
  `quality` 3→2→1→0 below 50 fps desktop / 28 fps touch; never steps up mid-session); level from Settings
  (`full | reduced | off`) and `prefers-reduced-motion`; `onLevel` / `onQuality` listeners.
- Primitives (each tiny, all routed through the engine or pure CSS/WAAPI): `reveal`, `stagger`, `splitText`,
  `typewriter`, `scramble`, `countUp`, `odometer`, `tilt`, `magnetic`, `parallax`, `flip`,
  `viewTransition`, `particles` (pooled burst emitter on one overlay canvas), `ripple`, `shake`, `glitch`,
  `sheen`, `marquee`, `scrollProgress`, `pin`, `sound` (synthesised Web Audio).
- `css/motion.css`: duration/easing tokens, keyframes, `animation-timeline: view()` scroll reveals with an
  IntersectionObserver fallback, and the level switches (`reduced`: fades/colour only; `off`: every
  duration 0).
- Only `transform`, `opacity`, `filter` (sparingly) and `clip-path` animate; `will-change` set only while
  running.

## Budgets
- Hub JS ≤ ~150 KB, CSS ≤ ~90 KB uncompressed (own code; no libraries). No runtime dependencies.
- Lighthouse desktop (local): Performance ≥ 90, Accessibility ≥ 95, Best Practices ≥ 95, SEO ≥ 95.
- CLS < 0.05 (every image has width/height, skeletons have final size). 60 fps hover/scroll on a laptop.
- Ambient particles ≤ 60 desktop / 20 phone; canvases stop when paused, hidden, off-screen or disabled.
