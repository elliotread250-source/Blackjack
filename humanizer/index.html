Settings

Models

Free by default: both run through Puter, which gives every visitor free Claude and GPT usage on a free Puter account (one click with Google, Microsoft or Apple). No API key, no card. If the server has its own keys it uses those instead.

Free detectors

These need no key. The open-source ones run inside your browser; the model files download once from Hugging Face, then they're cached.

Optional paid detectors

Only if you already pay for one of these. Keys stay in this browser and go only to this app's own server, which forwards them to that detector.

Pass marks

App password

Nothing can promise every detector forever: they retrain and disagree with each other. This keeps rewriting until every check you run passes, and if it runs out of rounds it hands you the version that scored best.
